# TiendaOnline - Sitio Web de Tienda Online

Un sitio web de tienda online con diseño minimalista que incluye catálogo de productos, dashboard de ventas y métricas.

## 🚀 Características

- **Página de Inicio**: Presentación de la tienda con características destacadas
- **Catálogo de Productos**: Grid responsivo con 12 productos de muestra
- **Dashboard de Ventas**: Métricas, estadísticas y análisis de ventas
- **Diseño Minimalista**: Interfaz limpia y moderna
- **Totalmente Responsivo**: Funciona en todos los dispositivos

## 📁 Estructura del Proyecto

```
firstwebsite/
├── index.html          # Página de inicio
├── catalog.html        # Catálogo de productos
├── dashboard.html      # Dashboard de ventas
├── styles.css          # Estilos minimalistas
├── catalog.js          # Lógica del catálogo
├── dashboard.js        # Lógica del dashboard
└── README.md          # Documentación
```

## 🎨 Características de Diseño

- Paleta de colores minimalista (azul, gris, blanco)
- Tipografía limpia con fuentes del sistema
- Diseño responsivo que funciona en todos los dispositivos
- Transiciones suaves y efectos hover
- UI basada en tarjetas para un aspecto moderno
- Espaciado y sombras profesionales

## 🚀 Cómo Usar

1. Clone el repositorio
2. Abra `index.html` en su navegador web
3. O use un servidor local:

```bash
python3 -m http.server 8000
```

Luego visite `http://localhost:8000` en su navegador.

## 📊 Secciones

### Inicio
- Hero section con llamada a la acción
- Tarjetas de características (envío, garantía, pago seguro)
- Navegación fácil al catálogo

### Catálogo
- 12 productos de muestra con precios y stock
- Grid responsivo de productos
- Íconos visuales para cada producto

### Dashboard
- Métricas clave: ventas totales, productos vendidos, pedidos, clientes
- Tabla de ventas recientes con estados
- Top 5 productos más vendidos con ingresos

## 🛠️ Tecnologías

- HTML5
- CSS3 (con Custom Properties)
- JavaScript (Vanilla)
- Diseño Responsivo
